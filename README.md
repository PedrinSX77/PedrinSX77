# 📌 Projeto backend em destaque

## 🗄️ CRUD API — Node.js + Express + Prisma + PostgreSQL

### 🔗 [Ver repositório](https://github.com/PedrinSX77/CRUD-Api-Node.js)

API REST criada durante meus estudos de desenvolvimento backend.

O projeto começou como um CRUD simples utilizando dados em memória e evoluiu gradualmente para uma API organizada em camadas e com **persistência real utilizando PostgreSQL e Prisma ORM**.

### Principais funcionalidades

- ✅ Listagem de produtos
- ✅ Busca por ID
- ✅ Criação de produtos
- ✅ Atualização parcial
- ✅ Exclusão
- ✅ Filtro por nome
- ✅ Filtro por preço máximo
- ✅ Validação de preço
- ✅ Validação de campos obrigatórios
- ✅ Tratamento de registros inexistentes
- ✅ Tratamento centralizado de erros
- ✅ Persistência com PostgreSQL
- ✅ Prisma ORM
- ✅ Prisma Migrate
- ✅ ES Modules
- ✅ Async / Await
- ✅ Variáveis de ambiente
- ✅ Arquitetura Route → Controller → Service
